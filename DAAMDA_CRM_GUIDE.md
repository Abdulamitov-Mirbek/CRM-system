### 3. Система управления бронированиями

#### Функции:
- ✅ Создание новых бронирований
- ✅ Выбор клиента из списка контактов
- ✅ Назначение столика (опционально)
- ✅ Указание количества гостей
- ✅ Установка времени начала и конца
- ✅ Добавление заметок и специальных пожеланий

#### Статусы бронирований:
1. **Ожидание** (Pending) - Новое бронирование, ожидает подтверждения
2. **Подтверждена** (Confirmed) - Бронирование подтверждено
3. **За столом** (Seated) - Клиент уже сидит за столом
4. **Завершена** (Completed) - Бронирование успешно завершено
5. **Отменена** (Cancelled) - Бронирование отменено

#### Действия над бронированиями:
- Ожидание → **Подтвердить** → Подтверждена
- Подтверждена → **За столом** → За столом
- За столом → **Завершить** → Завершена
- На любом этапе → **Отменить** → Отменена

#### Фильтрация:
- Фильтры по статусам: Все, Ожидание, Подтверждена, За столом, Завершена
- Поиск по имени клиента и количеству гостей

### 4. Компоненты системы

#### Карточка бронирования включает:
- **Имя клиента** с ID
- **Статус** с цветовой кодировкой
- **Дата и время** начала брони
- **Количество гостей**
- **Номер столика** (если назначен)
- **Заметки** (если добавлены)
- **Быстрые действия** для смены статуса

#### Форма создания бронирования:
- Выбор клиента из базы контактов
- Выбор столика (опционально)
- Количество гостей (1-50)
- Дата и время начала
- Дата и время конца
- Поле для заметок

### 7. API Endpoints

#### Бронирования
- `GET /api/reservations` - Получить все брони
- `POST /api/reservations` - Создать новую бронь
- `PUT /api/reservations/:id/status` - Обновить статус брони
- `DELETE /api/reservations/:id` - Удалить бронь

#### Контакты
- `GET /api/contacts` - Получить всех клиентов

#### Столики
- `GET /api/tables` - Получить все столики

## 🚀 Как использовать

### Создание брони:
1. Нажмите кнопку "Новая бронь" в верхней части страницы
2. Заполните форму:
   - Выберите клиента
   - (Опционально) Выберите столик
   - Укажите количество гостей
   - Установите время начала и конца
   - Добавьте заметки
3. Нажмите "Создать бронь"

### Управление статусом:
1. На карточке брони нажимайте кнопки действий
2. Следуйте логике: Ожидание → Подтверждена → За столом → Завершена
3. В любой момент можете отменить бронь

### Поиск и фильтрация:
1. Используйте поле поиска для поиска по имени клиента
2. Используйте кнопки фильтров для фильтрации по статусу
3. Комбинируйте оба для точного поиска
